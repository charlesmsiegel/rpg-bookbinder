# Heading ID Registry

Canonical anchor lookup for every internal cross-reference in PRISM. Anchors
follow standard markdown rules: lowercased, punctuation removed, spaces to
hyphens.

**Rules**
- Every heading in the outline has an entry here.
- A heading added during drafting must be added here *first*.
- Every internal cross-reference must use an ID from this table. No exceptions,
  and no hand-written anchors.
