# Default Voice

A minimal, neutral house style. Replace this file with your own voice guide and
point `voice.writing_style_file` at it (see README.md in this directory).

- Third-person, present tense for setting material; second person for player advice.
- Concrete nouns and active verbs; cut adjectives that don't earn their place.
- Vary sentence length; no more than two long sentences in a row.
- Humor by understatement, never by winking at the reader.
- State rules text plainly; save atmosphere for fiction and descriptions.
- Never use the banned phrases or names in `config/system.json` → `voice`.
