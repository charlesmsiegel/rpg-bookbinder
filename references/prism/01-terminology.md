# PRISM Terminology Reference

Binding. The consistency-checker validates every chapter against this file.

## The transformation/morph split

PRISM runs two registers at once: the magical-girl one (sincere, personal,
ceremonial) and the sentai one (punchy, collective, commanded). That mix is the
point. Uncontrolled it reads as sloppiness rather than range, so each word gets
exactly one grammatical job.

| Slot | Word | Use |
|---|---|---|
| **Noun** — the phenomenon, the concept, the chapter | **Transformation** | "Transformation is how PRISM escalates." |
| **Verb** — what a character does | **morph** | "When you morph…", "the morphing player". **Never** "transform" as a verb. |
| **Adjective** — the state you are in | **transformed** | "fought transformed", "your transformed form". |
| **Named moves** | **Solo Morph**, **Synchronized Morph**, **Combined Form** | Capitalized, always these exact names. |
| **Personal expression of it** | **Radiance** | The look, sound, phrase, object. Never a synonym for the act. |
| **Crossing into the Spectrum** | **refract** | Refracting and morphing are one act; never two steps. |
| **The two layers** | **the everyday** / **the Spectrum** | Lowercase "everyday", capitalized "Spectrum". Never "the real world" — both are real. |
| **The fusion gate** | **the Chord** | Stars *sound their note*. Never "meter", "gauge", or "bar". |

Transformation is the thing; morphing is the doing; transformed is the being.
One word per job, no overlap.

**The one licensed exception:** quoted in-world dialogue, where a character may
say whatever they like. Plus Chapter 1's single use of "player character" when
explaining the concept to a newcomer, immediately before the book renames them
Stars.

## Glossary

| Term | Meaning |
|---|---|
| **Star** | A player character. Never "player character" (except as above). |
| **Showrunner** | The GM. Never "Gamemaster". |
| **Number** | One session; one complete story. |
| **Trait** | Heart, Flash, Craft, or Cool. Rated +0 to +2. |
| **Heart** | Sincerity, courage, connection, standing your ground. |
| **Flash** | Speed, grace, performance, physical daring. |
| **Craft** | Cleverness, making, fixing, knowing. |
| **Cool** | Composure, style, reading a room, keeping it together. |
| **Refrain** | Your one-line creed. Drives Sparkle refresh. |
| **Signature** | The one thing you're unmistakably about. Drops a task one Difficulty band. Never a roll bonus. |
| **Bond** | A written line of shared truth with another Star. Spendable, finite. |
| **Look** | Your untransformed appearance. |
| **Radiance** | Your transformed form. |
| **Sparkle** | Personal resource. Starts 3, max 5. |
| **Shine** | Your 5-box resilience track. |
| **Dimmed** | At 0 Shine: out of the scene, present, not dead. |
| **Gloom** | The opposition. Clocks that start full and are emptied. |
| **the Chord** | The Combined Form gate. Every Star sounds a note. |
| **the Spectrum** | The hyper-saturated layer where the Gloom has a body. |
| **the everyday** | The modern world, exactly itself. |
| **refract** | To cross into the Spectrum. Same act as morphing. |
| **Flourish** | A success where both kept dice show 6. |
| **Finisher** | Transformed + 1 Sparkle: doubles the Gloom removed. |
| **Verse / Chorus / Bridge / Big Finish** | The four beats of a Number. |
| **Encore** | The between-Numbers downtime scene. |

## Forbidden

- `transform`, `transforms`, `transforming` as verbs (whole-word matches;
  `transformation` and `transformed` are correct and must not be flagged)
- `Gamemaster` (use Showrunner)
- Lowercase `combined form`, `solo morph`, `synchronized morph`
- `Difficulty 12` — Dazzling is 11
- Any Trait above +2
